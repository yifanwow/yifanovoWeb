# Yifanovo · 个人空间初稿

本地预览版本，保留旧站源码及部署入口。目前集中打磨诗歌，主导航收为「诗歌 / 项目 / 小家」。

## 首页

`/` 是首页（`home.js`、`home.css`），与诗歌页同一雨夜色调。首页想表达的不是时钟，而是时间本身：过去决定未来，而我们拥有的，只有此刻。

- 整页由约 820 根细线「零件」组成，在一张固定画布上以 3D 透视绘制。首屏它们组成「过去 · 现在 · 未来」：过去是一条向远处退去的螺旋，越久远越小、越远、越淡；现在是最前方明亮的一圈刻度，暖色的「现在」标记随真实秒数绕圈走动，文字「现在」跟着它移动；未来是同一条曲线向观者延伸出去的虚线，还没被画实。左下角写着「过去决定未来，而我们拥有的，只有此刻。」，下方是「Yifan Yu · 叙己 / 一个现实的浪漫主义者。」，右下角为社交链接与公众号二维码，现在是一块完整的表盘：外圈表盘边、放射状的底纹、表盘外侧的「十二 三 六 九」，六点位置有一个显示一天 24 小时的「昼夜」小表盘。一根时间轴从表盘中心穿过：表盘之后是过去，标着 2017、2019、2021、2023、2025（第一首诗写于 2017 年），到表盘处是「此刻」，之前是延伸向未来的虚线；过去的螺旋绕着这根轴退去，沿途漂浮着几张半透明的小画框，像经历过的片刻。表盘上有时针、分针（银色）和暖色秒针，秒针像机械表一样每秒跳一格、带一点回弹，螺旋的前端和「现在」标记也随之一格一格走。右上角为「此刻 01:36 · 夜」。
- 往下滚动，零件各自在不同时刻脱离、向外飞散，再拼成下一个栏目的造型，同时整体在空间中转向：诗歌是穿过空中落下的雨与水面涟漪（暖色雨滴代表诗）；项目是三层按齿比转动的齿轮、立柱与底部蓝图网格；摄影是斜视的镜头筒（镜圈、滚花握环、镜片）与开合的光圈；家居是线框房间（地面网格、窗光、吊灯、书架、桌子）；影视是一条带半扭的胶片环，持续转动，正前方一格发光；音乐是随波形起伏的环球，赤道一圈为暖色。鼠标移动时整体明显地转向光标，并像有重量一样略微滞后、轻轻回摆。按住鼠标（在链接和按钮以外的地方）拖动可以亲手转动当前的物件：左右拖是转，上下拖是俯仰；松手后它会顺势滑一会儿，停约两秒半再慢慢转回原位。手机上横向滑动可以转它，竖向滑动仍然是滚动页面。
- 每个造型在两个栏目之间的前 10% 与后 10% 路程里保持完整，其余路程都能看到拆散与重组；停在两个栏目之间、1 秒内没有滚动、触摸、点击或按键时，页面会先加速再减速地滑到最近的栏目（首屏则回到顶部，停在页面最底部时不动）；移动鼠标不算操作，任何滚动或按键都会立即中断滑动。
- 每个栏目约 0.6 屏高，只有最接近屏幕中线的栏目显示文字，其余模糊淡去；右侧细栏标记当前位置，悬停显示栏目名，点击前往。诗歌栏显示最新一首的日期与首句，项目栏列出作品，摄影栏显示三张照片；家居、影视、音乐显示简介与「即将到来」。
- 手机上造型在上方、文字在下方，不显示标注与侧栏。标签页隐藏时停止绘制。
- 场景定义在 `home.js` 的 `SCENES`，各自的观看角度在 `CAMERA`。
- `/home` 保留为家居（小家）占位页。页头品牌链接指向 `/`。

## 全站

- 网页标题：首页为「叙己 Yifanovo」，其他页面在前面加栏目名，如「诗歌 · 叙己 Yifanovo」。
- 页脚与首页一样列出 GitHub、Instagram、Steam、小红书和公众号；公众号悬停、聚焦或点按时显示二维码（`app.js` 统一处理，首页、页脚、索引通用）。
- 「索引」是一个全屏的雨夜色浮层：上方为「索引 INDEX」、当前时间与关闭；中间一行一个栏目（首页、诗歌、项目、摄影、家居，以及即将到来的影视、音乐），打开时逐行浮现，悬停时栏目名右移、下方细线展开，当前所在页面高亮；底部为社交链接。弹窗背后的遮罩由原来的墨绿色改为中性的深色。

## 项目

`/project`（`project.js`、`project.css`）与首页同一雨夜色调：

- 整页由一层代码贯穿（`project.js` 的 `mountCodeField`，固定在所有内容之后，页头下方逐渐淡出，导航不受影响）。首屏右侧是一个带透视的宽银幕画框（左远右近），`assets/code-film.mp4`（320×134、无声、循环）的每一帧被实时写成代码字符：字符先从四面八方飞来、自上而下依次落位，拼成画面；之后一道亮的扫描线逐行往下走，经过的那一行代码被改写。画框会跟着鼠标（手机上跟着手机的倾斜角度，iPhone 首次轻点首屏时会询问是否允许读取方向）轻微转动，像有重量一样慢慢跟上。画框周围是播放器式的界面（角标、时间码、帧号、解码状态、进度线），偶尔有一行横向错位（故障效果）。
- 这一群代码字符会随滚动在项目之间跳动：离开电影，沿弧线飞向 Mne，一部分落在它的每一个字上（标题、一句话介绍、描述、`{ platform… }`、链接、图注），字到位后先是乱码、再显出原文；其余拼成宣传图的代码版本。再往下，Mne 的字散回代码，整群飞到 watchDog 重新组成它的文字和图；往回滚则倒放。没被占据的画框留着一层很淡的代码残影。项目图平时就是代码版本，扫描线会在上面走过并改写代码；鼠标移上去（手机上第一次轻点）时，真实截图由上往下「显影」出来，第二次轻点才打开链接。滚动时画布逐帧重画，代码始终贴着页面走（大量字符在空中时最多每秒 45 帧）。代码群的旅程跟随滚动，但有速度上限：无论滑得多快，大约每 1.6 秒最多走一屏，落后太多时先跳近再飞，所以快速下滑时动画不会一闪而过。字落地时的亮度从起点平滑过渡到终点，不会整块泛白。和主页一样，停止操作 1 秒后，若页面停在两站之间（首屏、每个项目），会缓缓滑到最近的一站；早期项目列表和页脚不吸附；每段旅程两端各有一段停留区，相当于站与站之间的轻微阻尼。
- 页面上其余文字也由代码组成（`mountCodeText`）：首屏文案、小标题和早期项目列表进入视野时由乱码一扫而过解码成文字，离开时又散回乱码；乱码保持原文字的字体、字号和字重：西文变成其他字母、数字和符号，中文变成本页出现过的其他汉字。文字稳定后仍会不时有几个字闪回乱码，首屏标题区尤其频繁；鼠标掠过大标题时，附近的字会被打乱。「Beauty of Tech」偶尔还会出现青紫两色的错位撕裂。读屏软件读到的是完整的原文。首屏文案靠近屏幕底部，电影画框更大。文字下面没有深色底块，每个字自带一圈柔和的深色光晕，只在字的位置压暗背后的代码。这一页关闭了触控板的回弹（`overscroll-behavior`），否则回弹时会露出代码背景下的空白。这一页的强调色是蓝色。背景代码在某个项目处于视野中时偏向它的颜色（Mne 紫、watchDog 红）。字符来自 `assets/life-code.json`（为这一页写的「生活代码」，穿插各项目公开代码片段）。注意：`code-film.mp4` 截自商业影片，仅适合本地演示，正式上线前应换成自己拍摄的素材（替换这一个文件即可）。
- 「最近」：Mne 与 watchDog 各占一屏，左右交替。截图装在细框里，鼠标移上去会带重量感地朝光标倾斜；旁边是编号、名称、一句标语、简介、平台 / 年份 / 状态与链接（官网、GitHub）。截图取自两个项目自己的网站（`assets/project-mne.jpg`、`assets/project-watchdog.jpg`）。
- 「更早」：其余五个作品按年份排成索引，一行一个；悬停时名称右移、细线展开，光标旁浮出该项目的截图。
- 各部分滚动进入时由模糊浮现，离开时淡去。项目数据在 `content.json` 的 `projects`（含 `year`、`tagline`、`status`、`links`、`featured`），`import_content.py` 已同步，重新导入不会丢失。

## 诗歌

`/poetry` 可以独立访问，无须经过其他入口。57 首诗没有独立标题，以日期为标题，保留原文、断行、配图和日期链接。

- 首屏是「时间雨」：每首诗是一滴雨，竖排中文日期（如「二零二零年九月十日」）。横向位置按写作时间排列（一半按日历、一半按先后），写得多的年份雨更密；首屏不显示时间轴。地面是一个有透视的平面：远处的雨滴更小、落点更高，涟漪更扁；近处更大、落点更低，涟漪更圆。雨滴受重力加速，触地后继续缓缓下沉，每个字到达水面时向两侧散开、模糊并消失，像墨落入水中。鼠标附近的雨会放慢，悬停停住并显示日期与首句，点击读原文。右下角可暂停，减少动态效果设置下静止。
- 雨下面是日期列表：单栏居中，一行一个 `MM/DD/YYYY`，从新到旧；年份以中文数字作分隔（如「二 零 二 六」），不显示首句、首数或间隔。滚动进入时，每行像雨滴一样从上方落下、由模糊变清晰，上方拖一道很快消失的细雨痕；同时进入的几行依次落下。日期用较细、偏灰的数字；滚动时位于屏幕中间的日期变清晰、微微放大、转为暖白，离中间越远越淡越模糊（像景深），悬停或键盘聚焦时以该日期为焦点。列表在屏幕中段时，背景会从当前聚焦日期附近的十首诗里抓取词语（如「雨滴」「烛火」「霞光」），从下方慢慢浮起、由模糊到清晰再散去，像回忆涌上来。
- 页面最下方是「你的印记」：用浏览器自带的中文分词统计全部诗歌，桌面显示约 150 个、手机约 72 个最常出现的词，全部竖排，散落在整个屏幕宽度上，词与词之间约留一个字的空隙；最常出现的十几个词松散地聚成两三处，其余词散落在周围。词云和下方时间轨的高度按屏幕计算，一屏内完整显示。词频决定基础大小；每个词另有一个远近：近的更大、更暖、更清晰，远的更小、偏冷灰、略微模糊，都带一点柔和的外发光，不用纯白。淡出跟随滚动：这一段离开屏幕的部分越多，标题、词和时间轨整体越淡、越模糊（最多约 12px 模糊），往回滚又逐渐清晰；完全离开屏幕后，下次进入时词会各自错开、由模糊重新浮现。鼠标移动时近处的词移得多、远处的移得少，加上缓慢的晃动，形成立体感。悬停或键盘聚焦一个词，它放大、变清晰并高亮，其余词变模糊；下方时间轨显示它出现过的每一首。点击则在上方日期列表中只亮出含这个词的诗，再点或点「清除」取消。单字只保留白名单里的（如「你」「风」「雨」），虚词和「我/你/这/一」开头的短语被过滤，分别在 `poetry.js` 的 `CLOUD_KEEP`、`CLOUD_SKIP`。筛选不写进链接，也不带进正文。
- 点击日期后显示完整原文、断行与配图；页面保留返回和相邻日期导航。
- 去掉独立推荐、节选、阅读引导、搜索面板及海浪切换动效。背景为雨夜：无星光，薄雾和底部一点远处的暖光，按屏幕尺寸一次性画在 `.poetry-mist` 画布上，并混入细微噪点来消除暗色渐变的色带（只用于诗歌页），首屏不显示导语与诗歌节选。
- 中文、英文、数字统一使用衬线字体；三个入口继续共用页头与品牌「yifanovo / 叙己」。
- 返回索引时保留离开的位置；手机布局与系统减少动态效果设置均适配。

`poetry.js` 负责时间雨、日期列表、词云、原文和导航；`poetry.css` 负责雨幕层次、文字比例、对齐及留白。`ambient.js` 保留共享背景。

## 预览

在仓库根目录运行：

```sh
python3 site/serve.py
```

打开 http://localhost:4173 。无须安装依赖。`/` 是首页，`/home` 是家居占位页，其他栏目为 `/poetry`、`/article`、`/project`、`/photos`。

诗歌使用日期索引；文章保留全文搜索、年份与体裁筛选。每篇正文有独立 URL 和相邻篇目；随笔保留仓库原文链接，诗歌页只保留作品阅读。相册支持点击放大、方向键切换与 Escape 关闭。

## 内容来源

- `content.json` 从 esilhmt 仓库导入 57 篇诗歌、16 篇其他文字。保留原有文字与断行，统一展示日期。
- 两份相同的短句仅收录一次，空文件不生成页面；诗歌无独立标题，使用写作日期作为标题；首行保留在正文与列表预览中。
- 照片选自仓库中注明拍摄时间的个人照片；项目资料来自旧站。首页导语和照片短标题为本次初稿的编辑文案。
- `assets/` 保存相应配图及旧站项目截图。写作配图保留来源文章中的说明。
- 唱片播放使用 esilhmt 仓库的 `audio/いすぼくろ - ドリームレス・ドリームス.mp3`，复制到 `assets/home-track.mp3`，不自动播放。
- `import_content.py` 只读取两个仓库，不修改原文。默认从相邻的 `esilhmt` 文件夹导入，也可指定路径：

```sh
python3 site/import_content.py --source /path/to/esilhmt
```

## 静态导出

```sh
python3 site/build.py
```

输出到 `site/dist/`，包含各栏目和文章的 `index.html`，支持直接访问。部署时需要把此目录作为网站根目录；没有修改原有服务器、域名或线上发布配置。

中文、英文和数字统一使用本地 Noto Serif SC 可变字体子集，覆盖当前内容与界面；许可见 `assets/fonts/OFL.txt`。页面不依赖外部字体服务。新增内容后可用 `build_font.py` 扩展字形，静态预览与导出无须安装字体处理依赖。

## 性能说明

- 时间雨每帧只写入位置，不读取元素尺寸（尺寸在缩放和字体加载时测一次）；雨滴尾部渐隐用逐字透明度代替 CSS 遮罩；细雨线用一张预先画好的小图拉伸绘制。
- 滚动离开时间雨时，淡出直接写在雨幕这一层上，位置用缓存值计算；不用会被几百个雨滴字继承的 CSS 变量，也不在滚动时读取布局。淡出在动画帧里缓动跟随，滚轮一格一格时也是平滑的。
- 日期列表的焦点只在数值变化时写入；焦点日期不改变字重（字重变化会触发文字重排），只改变亮度、大小和清晰度。
- 「你的印记」分成远、中、近三层，鼠标视差只移动这三层；每个词的缓慢晃动是 CSS 动画，不占用主线程，离开视野时暂停。淡出模糊按 0.25px 分级，缓动跟随滚动，静止后动画循环自动停止。词浮现完成后取消错开的延迟，悬停时所有词同时响应。
- 诗歌页隐藏星空背景时，`ambient.js` 也停止绘制。
